# 测试

安装开发依赖后运行 `python -m pytest`。测试用小型解析场检查谱归一化、
角度符号、微分、FFT、完整卷积、显式截断、非线性近似和绘图接口。
绘图测试使用 Agg 后端；未安装 Matplotlib 或 cmap 时跳过。
实际渲染测试显式使用 `usetex=False`，检查实际角坐标、绘图选项及全局样式隔离；
TeX 测试仅检查对象设置，不触发渲染，不要求测试环境安装外部 LaTeX。

`test_surface.py` 检查圆环面与 Boozer 重参数化的解析度规、完整环面面积和体积，
用非轴对称曲面的位置差分验证基矢和符号，并检查周期旋转、广播、显式分辨率
以及 NPZ 对不同模态范围、坐标方向和异常元数据的处理。
